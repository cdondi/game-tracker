---
name: write-a-prd
description: Turn the confirmed requirements from a grill-me interview into a PRD saved as docs/prd.md.
---
Write a concise PRD to docs/prd.md with these sections: Problem, Users, Goals, Non-goals,
User stories, Data model, Acceptance criteria per story, Open questions.
Keep each user story small enough to build and test as one vertical slice.
